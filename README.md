# sport-matching

参考サイト **ドリームコーチング**（https://www.dream-coaching.com/）の
トップページを、静的サイト（HTML + CSS + JavaScript）で再現したものです。

スクリーンショットをもとに、構成・文言・配色・レイアウトを再現しています。

---

## 見た目を確認する方法

`index.html` をダブルクリックしてブラウザで開くだけです。
ビルド（変換作業）は必要ありません。

簡易サーバーで開きたい場合は次のとおりです。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 実装のポイント

### レイアウト
- 画面幅が変わっても崩れないようレスポンシブ対応。
- グリッドの列は `minmax(0, 1fr)` を使い、
  長い文章で枠が押し広げられないようにしています。
- `overflow-x` は `hidden` ではなく `clip` を使用。
  `hidden` だと追従ヘッダー（`position: sticky`）が効かなくなるためです。

### 日本語の改行
- `word-break: auto-phrase` で、文節（意味のかたまり）の切れ目で改行します。
- `line-break: strict` で「、」「。」が行頭に来るのを防ぎます。
- 見出しは `text-wrap: balance` で行の長さを揃えます。

### 外部依存なし
- ライブラリ・Webフォント・外部画像を一切使っていません。
- ファイルをそのまま開いても、オフラインでも表示できます。

## 元サイトと異なる点（重要）

参考サイトへのネットワークアクセスが遮断されていたため、
スクリーンショットからの再現です。次の点が元サイトと異なります。

### 1. 写真 → 自作イラストに置き換え
元サイトの写真は取得できないため、
同じ構図・同じ雰囲気の **SVGイラストを自作**しています。

### 2. PC表示は独自レイアウト
いただいたスクリーンショットはすべてスマホ表示のため、
PC（768px以上）のレイアウトは**こちらで設計**しています。

### 3. 未確認の箇所
- 競技カテゴリーの1件（名前が見切れていた箇所）を
  暫定で「**ダンス**」としています。
  該当箇所には `index.html` 内にコメントを入れてあります。
- よくある質問の**回答文**は元サイトで開いていない状態だったため、
  内容はこちらで補っています。
- 「グループレッスン」の説明文も見切れていたため補っています。

### 4. リンクはすべてダミー
全リンクはページ内アンカー（`#...`）です。
下層ページはまだありません。

### 5. チャット機能は未接続
「チャットで相談する」を押すと、
見た目の再現版である旨のメッセージが表示されます。
