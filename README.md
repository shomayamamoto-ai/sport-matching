# sport-matching

スポーツの個人指導マッチングサイト。
静的サイト（HTML + CSS + JavaScript）として制作しています。

現在は **土台（骨組み）だけができている状態** です。
参考サイトの素材が揃い次第、中身を差し替えていきます。

---

## 進め方の前提

- 参考にするサイト: https://www.dream-coaching.com/
- このセッションのネットワークは許可されたドメインにしか
  接続できないため、参考サイトを自動取得できません。
  そのため、素材を手元から共有してもらう方式で進めます。
- 必要な素材の集め方は
  [`docs/素材の集め方.md`](docs/素材の集め方.md) にまとめています。

---

## 見た目を確認する方法

### いちばん簡単な方法

`index.html` をダブルクリックしてブラウザで開くだけです。
ビルド（変換作業）は必要ありません。

### 開発用の簡易サーバーで開く場合

一部の機能を正しく確認したいときは、
簡易サーバー経由で開くのがおすすめです。

```bash
# Python が入っている場合
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## 色を変えたいとき

`assets/css/style.css` の先頭にある `:root { ... }` の中の
値を書き換えるだけで、サイト全体の色が一括で変わります。

```css
:root {
  --color-primary: #1a5fd0;  /* メインカラー */
  --color-accent:  #ff6b2c;  /* アクセントカラー */
}
```

## レイアウトの方針

- 画面幅が変わっても崩れないよう、
  レスポンシブ対応を前提にしています。
- 文字や画像が枠からはみ出さないよう、
  `max-width` と `overflow-wrap` を設定しています。
- スマホ幅（768px以下）では、
  メニューがハンバーガーボタンに切り替わります。
