# sport-matching

スポーツの個人指導マッチングサイト。
静的サイト（HTML + CSS + JavaScript）として制作しています。

**2つの版**が入っています。

| 版 | 場所 | 用途 |
|---|---|---|
| **再現版** | ルート（`index.html`） | 参考サイト（ドリームコーチング）の見た目を再現したもの |
| **独自ブランド版** | `brand/index.html` | 名称・配色・コーチ名を独自のものに差し替えた、公開しても安全な版 |

どちらも **全12ページ**（トップ + 下層11ページ）です。

---

## 見た目を確認する方法

`index.html` をダブルクリックしてブラウザで開くだけです。
ビルド（変換作業）は必要ありません。

独自ブランド版は `brand/index.html` を開いてください。

簡易サーバーで開きたい場合は次のとおりです。

```bash
python3 -m http.server 8000
# 再現版         → http://localhost:8000/
# 独自ブランド版 → http://localhost:8000/brand/
```

## 実装のポイント

### レイアウト
- 画面幅が変わっても崩れないようレスポンシブ対応。
- グリッドの列は `minmax(0, 1fr)` を使い、
  長い文章で枠が押し広げられないようにしています。
- `overflow-x` は `hidden` ではなく `clip` を使用。
  `hidden` だと追従ヘッダー（`position: sticky`）が効かなくなるためです。
- 2列の表はスマホで縦積みに切り替わります（`.table--stack`）。

### 日本語の改行
- `word-break: auto-phrase` で、文節（意味のかたまり）の切れ目で改行します。
- `line-break: strict` で「、」「。」が行頭に来るのを防ぎます。
- 見出しは `text-wrap: balance` で行の長さを揃えます。

### 外部依存なし
- ライブラリ・Webフォント・外部画像を一切使っていません。
- ファイルをそのまま開いても、オフラインでも表示できます。

### 共通部分について
ヘッダー・フッターは各HTMLファイルに**それぞれ書き込まれています**。
共通部分を直すときは、全ページを同じように直す必要があります。
（ビルド不要で開ける代わりのトレードオフです）

## 元サイトと異なる点

参考サイトへのネットワークアクセスが遮断されていたため、
スクリーンショットからの再現です。

### 1. 写真 → 自作イラストに置き換え
元サイトの写真は取得できないため、
同じ構図・同じ雰囲気の **SVGイラストを自作**しています。

### 2. PC表示は独自レイアウト
いただいたスクリーンショットはすべてスマホ表示のため、
PC（768px以上）のレイアウトは**こちらで設計**しています。

### 3. 「新体操」は推定です
競技カテゴリーの1件は、スクリーンショットで名前が見切れていました。
公開されている「人気の競技」の並び
（水泳・かけっこ・野球・陸上・サッカー・学校体育・**新体操**）から
「新体操」と判断しています。**確定情報ではありません。**
該当箇所は `index.html` 内にコメントを入れてあります。

### 4. 下層ページはすべて新規設計
下層ページのスクリーンショットはいただいていないため、
構成・文言・デザインはこちらで設計しています。
**掲載しているコーチ・料金・日程・口コミはすべて架空のサンプル**です。

### 5. フォームは送信されません
新規登録・ログイン・お問い合わせは見た目のみです。
入力してもどこにも送信・保存されません。

### 6. チャット機能は未接続
「チャットで相談する」を押すと、
見た目の再現版である旨のメッセージが表示されます。

      高橋洋昌／大山未希／藤田実桜／數田彩乃 の各氏）

- [ ] レッスンの日時・料金・開催場所

> **`brand/` の独自ブランド版は、上記をすべて差し替え済み**です。
> 公開を前提に進める場合は、こちらをベースにしてください。
> （コーチ名・口コミの投稿者名はすべて架空のサンプルです）
