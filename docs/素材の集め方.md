# 参考サイトの素材の集め方

しょーまさんへ。
参考サイト（https://www.dream-coaching.com/）を忠実に再現するために、
下の素材をいただけると助かります。

**全部そろわなくても大丈夫です。**
①だけでもかなり進みます。

---

## ⭐ おすすめ: そもそも私が直接見られるようにする

いちばん手間がかからない方法です。

Claude Code の環境設定で、**ネットワークの許可リスト**に
次のドメインを追加してもらえれば、
私が自分でサイトを読み込めるようになり、
素材集めの作業そのものが不要になります。

```
www.dream-coaching.com
```

設定方法は公式ドキュメントに記載があります。
https://code.claude.com/docs/en/claude-code-on-the-web

これが難しい場合は、下の方法で素材を共有してください。

---

## ① HTMLソース（最重要）

サイトの文言・見出し・構成が全部わかります。
**これがあれば再現の精度が一気に上がります。**

### PC（Chrome / Edge）の場合

1. https://www.dream-coaching.com/ を開く
2. ページの何もないところで **右クリック**
3. **「ページのソースを表示」** を選ぶ
4. 表示された文字を全選択（`Ctrl + A` / Mac は `⌘ + A`）
5. コピー（`Ctrl + C` / `⌘ + C`）
6. チャットに貼り付ける

### ファイルとして保存する方法（こちらでもOK）

1. サイトを開いた状態で `Ctrl + S`（Mac は `⌘ + S`）
2. 保存形式を **「ウェブページ、完全」** にして保存
3. できたファイル一式をチャットにアップロード

---

## ② スクリーンショット

配色・フォント・余白・画像の雰囲気を合わせるために使います。

- **PC表示** の全体キャプチャ
- **スマホ表示** の全体キャプチャ

> ページ全体を1枚に収めたい場合
> Chrome なら `F12` → `Ctrl + Shift + P` →
> `screenshot` と入力 → **「Capture full size screenshot」** を選ぶと、
> ページ全体が1枚の画像で保存できます。

---

## ③ 画像素材

ロゴや写真を実際に使う場合に必要です。

- ロゴ画像
- ヒーロー（トップの大きい）画像
- 各セクションで使われている写真・アイコン

> ⚠️ 注意
> 参考サイトは日本テレビが運営する公式サービスです。
> ロゴ・写真・キャッチコピーをそのまま公開すると、
> 著作権上の問題になる可能性があります。
> **社内での検討用・練習用にとどめるか、
> 公開する場合は自前の素材に差し替える**ことをおすすめします。

## 素材が届いたあとの作業

1. `reference/` フォルダに素材を保存
2. 構成（セクションの並び）を整理して確認
3. HTML の中身を実際の文言に差し替え
4. `style.css` の `:root` の色を実際の配色に合わせる
5. PC・タブレット・スマホの3つの幅で表示崩れをチェック
6. コミットして push
